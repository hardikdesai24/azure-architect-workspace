Findings

Inferred

Uniform automated 4xx probe traffic on every running app

All 7 apps show exactly 12 requests/hour, every hour, all 4xx, with zero variance — confirmed on app-HHS-prod-ncus's raw hourly series (12, 12, 12 … across all 12 buckets). This is almost certainly a health-check or monitoring probe hitting a path that returns 401/403/404. For four apps (audit-log, HHS, notification-service, PMM) this probe traffic is the only traffic recorded — zero 2xx in 12 hours.

The Http4xx metric doesn't expose the exact status code or path, so this is an inference, not a confirmed cause. Recommend pulling AppServiceHTTPLogs from Log Analytics (if diagnostic settings are enabled) for these apps in this window to identify the source and status code.

Inferred

Memory sustained at 72–90% on every Basic B1 plan

Memory percentage is elevated continuously (not just spiking) across all 7 plans, while CPU stays low (15–27% avg). B1 has no autoscale and is single-instance, so there's no burst headroom if any app's working set grows further.

Nothing is failing today — HTTP queue length is 0 and there are no 5xx responses — so this is a watch item, not an active incident.
